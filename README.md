# Econutri UI

## Project Overview

Econutri is a marketplace platform designed to reduce food waste by connecting consumers with food products approaching their expiration dates at discounted prices. Our mission is to make sustainable eating affordable while helping retailers minimize product losses and environmental impact.

## Features

- Browse foods nearing expiration with significant discounts
- Search and filter by product type, expiration date, and discount percentage
- Secure checkout and payment processing
- User profile and order history management
- Real-time inventory updates
- Push notifications for new deals and expiring discounts
- Sustainable packaging options
